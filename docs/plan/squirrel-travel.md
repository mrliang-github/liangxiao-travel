# 松鼠旅行官 1.2.0

## 问题与范围

公开行程页目前内嵌作者的地图 Key；未配置依赖的用户不能生成页面；首次使用要求自行阅读多段安装说明，恢复操作缺少任务状态。将公开名称改为「松鼠旅行官」，保留 `liangxiao-travel` 技术标识以兼容已有安装。

## 设计

- HTML 以每日行程为首屏，显示名称、概要、住宿和可保存的待办；提供「制作我的行程」安装/启动引导和 ima 文档导出。
- 首次使用在网页下载 Skill，在 WorkBuddy 导入后复制启动指令开始。网页不伪造本机安装状态，不收集 Key、手机号或验证码，也不假定存在官方深链。
- WorkBuddy 用结构化检查逐步引导地图助手安装、官方手机号验证、同程授权；只给当前一步。任务目录记录不含凭据的需求与配置选择，恢复时重新检测依赖。
- 支持用户明确选择基础版；没有连接器时不产生实查价格，没有地图授权时不编造坐标。默认增强流程保留同程日期核验。
- 页面默认无 Key；本地地图预览只能显式选择 `--local-map`。没有地图时仍提供明确标注的游览顺序图。公开生成不读取本机凭据。
- HTML 与适合 ima 阅读的 Markdown 都从同一份 JSON 生成。ima 保存经 WorkBuddy 官方入口授权，不承诺网页直接写入知识库。

## 文件边界

- `scripts/check_deps.py`：依赖状态、单步引导、非秘密状态恢复。
- `scripts/build_html.py` 与 `scripts/trip_document.py`：页面、公开生成、同源文档。
- `SKILL.md`、`INSTALL.md`、`README.md`、`references/`：品牌、首次启用及基础模式边界。
- `tests/`：无凭据生成、状态恢复、转义和现有日期解析回归。
- `outputs/1.2.0/`：永久保留的本地预览、ZIP 和参赛文案；不进 Git。

## 验证与交付

通过 workflow-runner 执行离线测试与生成；Chrome 核对桌面和手机尺寸、安装引导、复制回退、待办隔离、地图降级及文档导出。不运行短信申请、不修改现有 Key、不发起真实同程查询。平台授权、Windows 首装与 WorkBuddy 市场/灵感上架不以本地测试代替。

提交功能分支和可审阅产物；主分支合并与正式版本发布需按用户 Git 约定取得明确指令。投稿表单含参赛协议，由用户审阅确认。发布前安装下载入口必须与实际版本一致。
